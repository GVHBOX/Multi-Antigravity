# Multi-Antigravity

Google Antigravity 双开与多实例管理工具，支持主账号与分身账号在同一台电脑上同时运行，互不冲突。

---

## 它的作用

官方 Google Antigravity 默认只支持登录单个账号，切换账号需要反复登出。

Multi-Antigravity 为分身实例分配独立的本地运行目录：
- **主账号**：保持系统原生配置与登录状态不变。
- **分身账号**：配置与登录凭据保存在本地独立的 `data/instance_2` 目录中。
- **同时运行**：两个窗口独立运行，互不干扰，随时启动与退出。

---

## 使用方式

### 1. 桌面图形界面（默认）
直接运行根目录的 `multi-antigravity.exe` 或运行 `start.bat`。

1. 打开管理器，界面显示主账号与分身状态。
2. 按快捷键 **Space** 或界面「启动」按钮，启动分身。
3. 在弹出的分身窗口中登录第二个 Google 账号。

### 2. 终端字符界面（TUI）
在命令行运行：
```powershell
.\multi-antigravity.exe --tui
```
或运行 `start_tui.bat`。

## 快捷键

| 按键 | 功能 | 说明 |
| :---: | :--- | :--- |
| **<kbd>Space</kbd>** | 启动 / 停止 | 未运行时启动分身；运行中时关闭分身 |
| **<kbd>K</kbd>** | 停止分身 | 终止分身进程 |
| **<kbd>R</kbd>** | 重启服务 | 重启分身后台服务 |
| **<kbd>C</kbd>** | 退出账号 | 清除分身登录凭据，下次启动重新选账号 |
| **<kbd>O</kbd>** | 打开目录 | 打开分身本地数据文件夹 (`data/instance_2`) |
| **<kbd>L</kbd>** | 切换日志 | 切换查看系统运行记录与各组件日志 |
| **<kbd>P</kbd>** | 代理设置 | 切换本地 7890 端口代理支持 |

## 账号安全与风险评估

根据 Google Antigravity 及相关服务条款，本工具的安全特征与合规边界如下：

### 1. 凭据与网络安全
- **零反向代理**：工具不搭建任何中间网络代理或中继服务器。客户端直接通过 HTTPS 与 Google 官方服务器通信，不存在第三方窃取或拦截凭据的链路。
- **本地存储**：分身的登录凭据（OAuth Token）仅存储在用户本机磁盘的 `data/instance_2/` 目录下，不向任何第三方上传遥测或个人数据。
- **原生程序运行**：工具不修改、不反编译 Antigravity 官方可执行文件，通过系统标准环境变量将数据路径指向独立目录。

### 2. 服务条款（ToS）风险提示
- **合理使用**：双账号用于日常不同项目或工作/个人身份分工属于常见场景。
- **滥用风险**：若利用多开并发刷取免费配额、批量自动化调用或规避服务频率限制，可能违反 Google 针对生成式 AI 服务的可接受使用政策（AUP），存在被服务商风控拦截或限制账号的风险。使用时需遵守相关服务条款。

## 从源码构建

需要 Rust 1.85+ 及 MSVC 构建工具：

```powershell
cargo build --release
```

编译产物位于 `target\release\multi-antigravity-rust.exe`。
